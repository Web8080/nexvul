Dashboard app shell (local report, v1)

White by default, dark as an alternate. No accounts, sign-in or server (DEC-0009); Settings is read-only.

Open the live mock-up: assets/report-preview.html

Views: Overview, Findings, Frameworks and agent map, Rules, Suppressions, Scan history (this run only), Settings, Help. Use Preview state in the top band to switch between a complete and a partial scan.

Deep links: #findings/F3, #findings/sev=high, #findings/rule=NEX015, #settings.
