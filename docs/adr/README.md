# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records for the nexvul project.
ADRs document significant technical decisions, the context behind them, the
options considered, and the rationale for the chosen approach.

## Index

| ADR | Title | Status | Date |
|---|---|---|---|
| [0000](0000-template.md) | ADR Template | — | — |
| [0001](0001-parser-and-static-analysis-architecture.md) | Parser and Static Analysis Architecture | Proposed | 2026-10-08 |

## Process

1. Copy `0000-template.md` to `NNNN-short-title.md`
2. Fill in all sections honestly — include trade-offs and risks
3. Set status to **Proposed**
4. Review with the team
5. Update status to **Accepted** or **Deprecated**

## Status Lifecycle

```
Proposed --> Accepted --> [Deprecated | Superseded by ADR-XXXX]
```

A superseded ADR links to its replacement. Deprecated ADRs stay in the
directory for historical context.
