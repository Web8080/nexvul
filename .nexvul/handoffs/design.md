## 2. What implementers must not miss

1. **T06** (partial, no findings) must never print the T02 sentence. Test it by name.
2. Status line and partial banner are printed **last**, from trusted strings, never removed by `--quiet`.
3. No green anywhere; zero-finding results are neutral ink.
4. Severity = word + meter + colour; confidence = word only.
5. Every fixed sentence comes from `tokens.json → copy`; copy lint enforces `design-system.md` §8.1.
6. One sanitiser, three render targets (terminal `Text`, HTML text node, Markdown code span) — CA-6.
